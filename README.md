# Хроника государств — карта и статистика ВПИ

Сайт военно-политической игры: общая карта мира и статистика государств.

## Как устроено

- `index.html`, `assets/` — сайт (Leaflet, без сборки).
- `tiles/{z}/{y}/{x}.webp` — карта мира, нарезанная на плитки 256×256 из Figma-экспорта (13631×6760). Уровень 6 — исходный масштаб.
- `data/states.json` — государства и их статистика (сейчас демо).
- `data/borders.geojson` — границы государств в пикселях исходной карты (x вправо, y вниз).

Сейчас сайт работает в демо-режиме: вход `demo` / `demo` открывает полную статистику Арнорского королевства.
Когда будет готов сервер на Apps Script, его адрес вписывается в `CONFIG.apiUrl` в `assets/app.js`, и данные пойдут из таблиц.

## Запуск локально

```
python3 -m http.server 8000
```
и открыть http://localhost:8000
