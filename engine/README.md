# Движок хода

Движок — отдельный проект Apps Script на вашем Google-аккаунте. Сайт присылает ему команду, Движок открывает таблицу государства и выполняет тот же код, что и «Мастер хода» внутри таблицы: превью, запись приказа, ход. Перед каждым ходом он кладёт копию таблицы в папку «ВПИ — бэкапы перед ходом» на вашем Диске. Номер хода проверяется, поэтому повторное нажатие или повтор из очереди не применят ход дважды.

Таблицы государств менять не нужно: Движок работает с таблицами Код.gs v15 как есть, старый «Мастер хода» внутри таблиц продолжает работать.

## Файлы

- `Код.gs` — Код.gs версии 15.1. Расчёты те же, что в 15.0, но код может работать и внутри таблицы, и в Движке. Его же можно вставлять в таблицы вместо 15.0 (необязательно).
- `Движок.gs` — приём команд с сайта.
- `appsscript.json` — настройки проекта: часовой пояс, режим веб-приложения.

## Установка (один раз, с компьютера)

1. Откройте https://script.google.com под тем же аккаунтом, которому принадлежат таблицы государств. «Новый проект», назовите его «ВПИ — Движок хода».
2. В файл `Код.gs` проекта вставьте содержимое `engine/Код.gs` целиком.
3. «+» рядом с «Файлы» → «Скрипт», имя `Движок`. Вставьте содержимое `engine/Движок.gs`.
4. «Настройки проекта» (шестерёнка) → галочка «Показывать файл манифеста appsscript.json». Откройте `appsscript.json` и замените содержимое на `engine/appsscript.json`.
5. Вверху выберите функцию `setupEngine` → «Выполнить». Google попросит доступ к таблицам и Диску, разрешите. Внизу, в «Журнале выполнения», появится ключ Движка: скопируйте его.
6. «Развернуть» → «Новое развёртывание» → тип «Веб-приложение». Выполнять от имени: «Меня». У кого есть доступ: «Все». «Развернуть», скопируйте адрес `https://script.google.com/macros/s/…/exec`.
7. На сайте: «Управление» → «Настройки», впишите адрес и ключ Движка, «Сохранить настройки», затем «Проверить Движок». Должно появиться «Движок отвечает, версия 1.0».

Доступ «Все» нужен, чтобы сервер сайта мог достучаться до Движка. Без ключа Движок ничего не делает, а ключ хранится только в Движке и в базе сервера: на сайт он не возвращается.

## Первая проверка на копии таблицы

1. Сделайте копию таблицы любого государства («Файл» → «Создать копию»).
2. В Движке, в функции `testEngineOnCopy` (внизу `Движок.gs`), вставьте ID копии (часть ссылки между `/d/` и `/edit`). Выберите эту функцию → «Выполнить». В журнале появится превью хода, его можно сравнить с «Превью» Мастера хода в той же копии.
3. Чтобы проверить сам ход, временно привяжите копию к тестовому государству на сайте («Указать готовую»), откройте вкладку «Ход», «Превью», галочку, «Новый ход». В копии должна появиться новая строка Журнала, а на Диске — копия «перед ходом».

## Как идёт «Новый ход»

- Вкладка «Ход» на сайте показывает все действующие государства, номер хода, проблемы таблиц и галочку «данные хода заполнены». Галочка ставится на конкретный номер хода, после хода она сама перестаёт действовать.
- «Новый ход» доступен, когда у всех стоит галочка и все таблицы читаются. Его надо подтвердить двумя галочками.
- Сервер ставит государства в очередь и раз в минуту отправляет Движку до трёх штук. Статус каждого (в очереди, применён, ошибка) виден на вкладке; при ошибке есть «Повторить». Страницу можно закрыть.

## После правки Код.gs

Вставьте новый код в проект Движка и обновите развёртывание: «Развернуть» → «Управление развёртываниями» → карандаш → версия «Новая версия» → «Развернуть». Адрес останется тем же.
